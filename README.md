# STG Schülerzeitung

Apps for the school newspaper of the Städtisches Gymnasium Bad Segeberg – https://stg-sz.net ("Schüler texten Gedanken").

- **`mobile/`** – the current app (v2): Expo / React Native for iOS and Android. See [mobile/README.md](mobile/README.md).
- **`wordpress/`** – the must-use plugin that gives the app its API and push notifications. See [wordpress/README.md](wordpress/README.md).
- **`app/`** (and the Gradle files in the root) – the original Android-only app from 2019, kept for reference only.
